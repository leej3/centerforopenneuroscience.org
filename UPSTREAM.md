# Upstream adoption

The `orinoco-lite` branch continues the existing CON website history. It does
not merge or graft the complete `www-from-model` history.

Exact source revisions are recorded in `provenance/imports.yaml`. Upstream code
is adopted in focused commits so that each import can be reviewed, updated, or
contributed back independently.

`con/www-from-model` remains the clean GitHub mirror used to compare upstream
changes. Generally useful adaptations should be developed there and offered to
the original project separately from CON metadata, content, and presentation.
